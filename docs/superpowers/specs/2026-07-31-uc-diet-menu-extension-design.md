# 울산과학대 교직원식당 식단표 크롬 확장프로그램 설계

## 배경
https://www.uc.ac.kr/www/CMS/DietMenuMgr/listByWeek.do?mCode=MN207 페이지는 동부/서부 교직원식당의 주간(월~금) 점심 메뉴를 서버 렌더링된 HTML 테이블로 제공한다. 페이지에는 영양성분(칼로리 등) 데이터가 존재하지 않는다 — 확인 결과 메뉴 이름 텍스트만 있고, 별도 영양정보 컬럼/데이터는 없다.

## 목표
확장프로그램 아이콘 클릭 시 팝업에 **동부캠퍼스** 교직원식당의 **오늘 점심 메뉴**를 크게 보여주고, 이전/다음 날 버튼으로 다른 날짜 메뉴를 탐색할 수 있게 한다.

## 스코프 밖 (의도적으로 제외)
- 영양성분 표시 — 원본 데이터 없음
- 서부캠퍼스 — 사용자가 동부만 요청
- 주간 전체 표 뷰 — "오늘 메뉴 크게" 방식으로 결정
- 알림/뱃지, 자동 새로고침, 백그라운드 서비스워커

## 구조
파일 3개, 외부 의존성 없음(순수 JS/HTML, Manifest V3).

- `manifest.json` — `action.default_popup`만 사용. 백그라운드 스크립트/컨텐츠 스크립트 없음. `host_permissions`에 `https://www.uc.ac.kr/*` 필요 (팝업에서 fetch 시 CORS 우회용).
- `popup.html` — 날짜/요일 표시 영역, 메뉴 리스트, ◀ ▶ 버튼, 로딩/에러 상태 영역.
- `popup.js` — fetch, HTML 파싱, 렌더링, 날짜 이동 로직.

## 데이터 흐름
1. 팝업 오픈 시 `listByWeek.do?mCode=MN207&searchDietCategory=4`를 GET fetch.
2. 응답 HTML을 `DOMParser`로 파싱해 `.menu-core table` 내 `thead`에서 요일/날짜 5개, `tbody`의 "점심" 행에서 각 요일 `<td>`의 메뉴 텍스트(`<br>` 구분)를 추출.
3. 로컬 오늘 날짜와 일치하는 컬럼을 찾아 기본 표시. 없으면(주말 등) "오늘은 운영일이 아닙니다" 상태를 보여주되 ◀▶로 평일 탐색은 가능하게 함.
4. ◀▶ 클릭:
   - 이동 대상이 이미 불러온 주(월~금) 범위 안이면 캐시된 데이터에서 인덱스만 이동.
   - 범위를 벗어나면(금요일에서 다음 / 월요일에서 이전) 현재 페이지의 "이전주/다음주" 버튼 `onclick` 속성에 박힌 `searchWeek` 값을 그대로 읽어, `mCode=MN207&searchWeek=<값>&searchDietCategory=4`로 POST fetch 후 같은 방식으로 파싱. 진입 인덱스는 다음주면 0(월), 이전주면 4(금).

## 에러 처리
- fetch 실패(네트워크 오류) 또는 기대한 테이블 구조가 없는 경우(방학 등 미운영) → 팝업에 "정보를 불러올 수 없습니다" 안내만 표시하고 확장프로그램은 정상 동작 유지.

## 검증
자동화 테스트 프레임워크 없이, 언패킹된 확장프로그램을 크롬에 직접 로드하여 다음을 수동 확인한다:
- 아이콘 클릭 시 오늘 메뉴 정상 표시
- ◀▶ 버튼으로 같은 주 내 다른 요일 이동
- 주 경계를 넘는 이동(예: 월요일에서 이전 클릭 → 지난주 금요일) 정상 동작
- 네트워크 오류/구조 없음 상황에서 에러 메시지 표시
