# 울산과학대 교직원식당 식단표

울산과학대학교 동부캠퍼스 교직원식당의 이번 주 점심 메뉴를 보여주는 Chrome 확장 프로그램입니다.

## 기능

- 툴바 아이콘 클릭 시 오늘의 점심 메뉴를 바로 표시
- ◀ / ▶ 버튼으로 이전/다음 날짜 메뉴 탐색 (주간 경계에서는 자동으로 다음/이전 주 데이터 로드)
- 학교 홈페이지(uc.ac.kr)에서 식단표를 직접 가져와 파싱

## 설치 (개발자 모드)

1. 이 저장소를 클론하거나 다운로드합니다.
2. Chrome에서 `chrome://extensions` 접속
3. 우측 상단 "개발자 모드" 활성화
4. "압축해제된 확장 프로그램을 로드합니다" 클릭 후 이 프로젝트 폴더 선택

## 구조

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 프로그램 매니페스트 (MV3) |
| `popup.html` / `popup.js` | 팝업 UI 및 날짜 탐색 로직 |
| `diet.js` | 학교 식단표 페이지 fetch 및 HTML 파싱 |
